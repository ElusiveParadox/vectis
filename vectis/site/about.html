How this page reached you

  1. DNS: your Mac asked the Vectis DNS server where this name lives; it answered with the load balancer's IP.
  2. Load balancer: nginx accepted the HTTPS connection and chose a backend (least connections).
  3. Backend __VECTIS_BACKEND__ sent this page (request __VECTIS_REQUEST_ID__).

If a backend is down, nginx retries on the other one and you still get a page.
